## 1. ดูแท่งเทียนมากกว่าแค่สี

ให้ดู **จุดเปิด จุดปิด และไส้ทั้งสองข้าง** ไม่ใช่แค่สี

- **แท่งขาขึ้น (เขียว)**: ปิด > เปิด → จุดเปิดอยู่ล่าง จุดปิดอยู่บน
- **แท่งขาลง (แดง)**: เปิด > ปิด → จุดเปิดอยู่บน จุดปิดอยู่ล่าง

## 2. Range กับ Liquidity

```
     แท่งเขียว (ขึ้น)              แท่งแดง (ลง)

        │  ← Range                   │  ← Liquidity
      ┌───┐ ← ปิด                  ┌───┐ ← เปิด
      │   │                        │   │
      │   │                        │   │
      └───┘ ← เปิด                 └───┘ ← ปิด
        │  ← Liquidity               │  ← Range
```

| | ไส้บน | ไส้ล่าง |
|---|---|---|
| แท่งเขียว | **Range** | **Liquidity** |
| แท่งแดง | **Liquidity** | **Range** |

**วิธีจำ (ใช้ได้ทั้งสองสี):** ไส้ฝั่ง **จุดปิด** = **Range** · ไส้ฝั่ง **จุดเปิด** = **Liquidity**

## 3. ไม่มี Range = 50/50

แท่งที่ไม่มี Range คือแท่งที่ปิดตรงปลายสุด (เขียวปิดที่ high, แดงปิดที่ low)
→ แท่งต่อไปมีโอกาสขึ้นหรือลง **50/50**

**ตัวอย่างเศษขนมปัง:** เราเดินในป่าไปทางถ้ำ แล้วโรยเศษขนมปังไว้ตลอดทาง
- **มีเศษขนมปัง** → เพื่อนที่ตามมาดูรอยแล้วรู้ว่าเราไปทางถ้ำ
- **ไม่มีเศษขนมปัง** → เพื่อนไม่รู้ว่าเราเข้าถ้ำไปแล้ว หรือออกไปทางอื่น

Range คือ "รอยเศษขนมปัง" ของราคา แท่งที่ไม่มี Range ไม่ทิ้งรอยไว้ จึงเดาทิศทางต่อไม่ได้

**นำไปใช้ — No Range หักล้างทุก confirm:**
- แท่งที่จะใช้ตัดสินใจเข้าไม่มี Range → **ไม่เข้า** ต่อให้มี confirm อื่นครบ (เทรนด์, แนวรับแนวต้าน) ก็ตาม
- **แท่งตัน** (ไม่มีไส้ทั้งสองข้าง) ก็ 50/50 ไม่ควรเข้า แท่งจะแรงแค่ไหนก็ไม่มีผล
- ใช้เป็นตัวกรองด่านแรก (veto) → รอแท่งถัดไปที่มี Range

## 4. ไม่มี Liquidity = Volume เยอะ

แท่งที่ไม่มีไส้ฝั่งจุดเปิด (เขียวเปิดที่ low, แดงเปิดที่ high) แปลว่า **volume เยอะ**
เพราะเปิดแล้ววิ่งไปทางเดียวจนปิด ไม่ย้อนกลับไปเลยจุดเปิด → ฝั่งเดียวคุมตลาดทั้งแท่ง

```
  เขียว ไม่มี Liquidity        แดง ไม่มี Liquidity

        │  ← Range              ┌───┐ ← เปิด = high
      ┌───┐ ← ปิด               │   │
      │   │                     │   │
      └───┘ ← เปิด = low        └───┘ ← ปิด
                                  │  ← Range
```

## 5. อ่าน Volume จากเนื้อและไส้

**5.1 เนื้อเทียน:** ยิ่งยาว ยิ่ง volume เยอะ

**5.2 ไส้เทียน** (เทียบแท่งที่เนื้อยาวเท่ากัน): **ไส้สั้นกว่า = volume เยอะกว่า**
เพราะไส้ยาวแปลว่าราคาขึ้นไปได้แล้ว แต่โดน sell ตบกลับมา → แรงซื้อเหลือสุทธิน้อยกว่า

```
     A          B
     │
     │          │
   ┌───┐      ┌───┐
   │   │      │   │
   │   │      │   │
   └───┘      └───┘
  เนื้อเท่ากัน → B ไส้สั้นกว่า = volume เยอะกว่า
```

**5.3 ดูหลายแท่งต่อกัน:**

เนื้อสั้นลงเรื่อย ๆ = **volume กำลังน้อยลง** (ใช้ได้ทั้งขาขึ้นและขาลง) → ราคามีโอกาส **กลับตัว**

```
ขาขึ้น:  ████████  →  █████  →  ███  →  ┼ (เกือบไม่มีเนื้อ)
ขาลง:   ████████  →  ████   →  ██
volume:  เยอะ ─────────────────────────▶ น้อยลง
```

เนื้อยาวขึ้นเรื่อย ๆ = **volume มากขึ้น** (ตัวอย่างของครูเป็นขาขึ้น)

```
แบบที่ 1:  ██  →  █████  →  ████████
แบบที่ 2:  ┼   →  ███    →  ████████   (เริ่มจากแท่งที่เกือบไม่มีเนื้อ)
volume:    น้อย ──────────────────────▶ มากขึ้น
```

**นำไปใช้ — เข้าเทรดต้องมี volume:**
ถ้าแท่งบอกว่า volume น้อยหรือกำลังน้อยลง → ไม่เข้าตาม แม้ราคายังไปทางเดิมอยู่

## 6. BO กับ Volume

**กฎ: BO แล้ว Buy ได้ แต่ต้องดู volume ด้วย**

**✓ ตัวอย่างที่ Buy ได้**
1. ราคา sideway ระหว่างแนวรับกับแนวต้าน
2. แท่งเขียวเนื้อเล็ก → กลาง → ยาว = volume มากขึ้นเรื่อย ๆ
3. แท่งเนื้อยาวทะลุแนวต้าน (BO) → **Buy** ที่ราคาปิดของแท่ง BO
   - **SL**: ใต้ low ของแท่ง BO
   - **TP**: ด้านบน (ครูไม่ได้บอกระยะ)

**✗ ตัวอย่างที่ไม่ควร Buy**
1. ราคา sideway ระหว่างแนวรับกับแนวต้าน
2. แท่งเขียวเนื้อยาวขึ้นมาจากกลางกรอบ → แท่งต่อมาเนื้อสั้นลง
3. แท่งที่ BO แนวต้านเนื้อเล็กนิดเดียว → volume หมดตั้งแต่ก่อน BO → **ไม่ควร Buy**

**⚠ ตัวอย่าง BO แล้วแรงหมด**
1. ราคา sideway แล้วแท่งเขียวเนื้อยาว BO → Buy ที่ราคาปิดของแท่งนี้
2. แท่งต่อมาเนื้อสั้นลง → แท่งถัดไปแทบไม่มีเนื้อ = volume หมด
3. แท่งแดงเนื้อยาวมา → **ราคากลับตัว**

→ BO แล้วต้องดูต่อว่า volume ยังอยู่ไหม ถ้าลดลงเรื่อย ๆ ราคามีโอกาสกลับตัว

| | Buy ได้ | ไม่ควร Buy |
|---|---|---|
| เนื้อแท่งก่อน BO | ยาวขึ้นเรื่อย ๆ | สั้นลงเรื่อย ๆ |
| แท่งที่ BO | ใหญ่ที่สุด | เล็กนิดเดียว |
| volume | เพิ่มขึ้นจนถึง BO | หมดก่อน BO |

## 7. Wick fill

**Wick fill** = ปิดแท่งแล้ว ราคาย้อนก่อน แล้ววิ่งกลับไปถึงปลายไส้ของแท่งเดิม (ไส้เดิมโดน "เติมเต็ม")

- **ขาขึ้น:** แท่งเขียวเหลือไส้บน → แท่งถัดไปย้อนลงก่อน (ไส้ล่างยาว) แล้วขึ้นไปถึงปลายไส้บนของแท่งเดิม
- **ขาลง:** แท่งแดงเหลือไส้ล่าง → แท่งถัดไปย้อนขึ้นก่อน (มีไส้บน) แล้วลงไปถึงปลายไส้ล่างของแท่งเดิม

**Wick fill ต้องใช้ volume:**
แท่งถัดไปต้องมี volume พอจะเติมไส้ของแท่งก่อนหน้าให้เต็มก่อน ถึงจะไปต่อทางเดิมได้
→ ไส้ยิ่งยาว ระยะที่ต้องเติมยิ่งไกล ต้องใช้ volume ยิ่งเยอะ → มีโอกาสไปต่อ แต่น้อย

### ภาพจำ — สัดส่วนไส้ต่อเนื้อ

แท่งเขียวเนื้อยาวเท่ากัน ต่างกันแค่ความยาวไส้บน → **2 แท่งซ้ายดี 2 แท่งขวาไม่ดี**

```
 ✓✓    ✓     ✗     ✗✗
                    │
                    │
              │     │
        │     │     │
  │     │     │     │
 ███   ███   ███   ███
 ███   ███   ███   ███
 ███   ███   ███   ███
 ███   ███   ███   ███
 ███   ███   ███   ███
```

| แท่ง | ไส้บนเทียบเนื้อ (กะจากรูปวาด) | ครูให้ |
|---|---|---|
| 1 | ~1/5 ของเนื้อ | ✓✓ ดี |
| 2 | ~1/3 ของเนื้อ | ✓ ดี |
| 3 | ~3/5 ของเนื้อ | ✗ ไม่ดี |
| 4 | ~เท่ากับเนื้อ | ✗✗ ไม่ดี |

- **ไส้สั้น** → แท่งต่อไปใช้ volume ไม่มากก็เติมไส้ได้ → มีโอกาสไปต่อ
- **ไส้ยาว** → ต้องใช้ volume เยอะมากกว่าจะเติมไส้ได้ → มีโอกาสไปต่อ แต่น้อย

(ครูให้จำเป็นภาพ ไม่ได้ให้ตัวเลข ตัวเลขในตารางเรากะเองจากรูป)

## 8. ธรรมชาติของแท่งเทียน — ขึ้น ย่อ ขึ้น ย่อ

ราคาขึ้นอย่างเดียวตลอดไม่ได้ ต้องมีการพักตัว → **ขึ้น → ย่อ → ขึ้น → ย่อ**

```
                    /
             /\    /
      /\    /  \  /
     /  \  /    \/
    /    \/
  ขึ้น  ย่อ  ขึ้น  ย่อ  ขึ้น
```

## 9. แท่ง Confirm และจังหวะเข้า

ก่อนเข้า Buy หรือ Sell ต้องมี **แท่ง confirm 1 แท่ง ไปในทางที่จะเข้า**
- จะ Buy → แท่งก่อนหน้าต้องเป็นแท่ง Buy (เขียว)
- จะ Sell → แท่งก่อนหน้าต้องเป็นแท่ง Sell (แดง)

**จังหวะเข้า:** เข้า **1 วินาทีหลังแท่ง confirm ปิด** → ต้องรอแท่งปิดจริงก่อน ห้ามเข้าตอนแท่งยังวิ่งอยู่
(เวลา backtest = เข้าที่ราคาเปิดของแท่งถัดไป)

**✓ ตัวอย่าง Buy ได้**
1. แท่งเขียวเนื้อยาว มีไส้บน
2. แท่งแดง (ย่อ) → ยัง Buy ไม่ได้
3. แท่งเขียว = แท่ง confirm → **Buy หลังแท่งนี้ปิด**

```
  ─┬─────────────── ← wick fill (?)
   │
 ┌───┐       ┌───┐ ← Buy ✓
 │   │ ┌───┐ │   │
 │   │ │▒▒▒│ │   │
 │   │ │▒▒▒│ │   │
 │   │ └───┘ └───┘
 │   │   │     │
 └───┘
   │
 เขียว  แดง  เขียว
```

**✗ ตัวอย่าง ราคากำลังขึ้น จะ Sell ไม่ได้**
แท่งเขียวมีไส้ล่างยาว → อยาก Sell หวังให้ราคาลงไป wick fill ไส้ล่าง
→ **ไม่ได้** เพราะแท่งล่าสุดเป็นขาขึ้น ยังไม่มีแท่ง confirm ขาลง

```
     │
   ┌───┐ ← อยาก Sell ตรงนี้ ✗ (แท่งเขียว = ยังขึ้นอยู่)
   │   │
   │   │
   └───┘
     │
     │
  ───┴─── ← เป้า wick fill
```

## 10. ท่าที่ครูเล่น — Wick fill 4H → หาจุดเข้า 30M

ใช้ timeframe ใหญ่ (4H) หาเป้า แล้วลงไป timeframe เล็ก (30M) หาจุดเข้า

**4H — หาเป้า**
1. แท่งเขียวเนื้อยาว มีไส้บน → **ปลายไส้บน = เป้า wick fill**
2. แท่งถัดไปเป็นแท่งเขียวเล็ก ๆ
3. ไปหาจุดเข้าจริงใน 30M

**30M — หาจุดเข้า**
1. ราคาขึ้นไปทำ high
2. ย่อลงมา
3. เริ่มขึ้นอีกรอบ → **Buy**
4. เป้า = high เดิม = ปลายไส้ของ 4H (wick fill)

```
30M:           high เดิม = ปลายไส้ 4H ← เป้า
                /\ . . . . . .
               /  \         :
              /    \   ___ Buy
             /      \ /
            /        V
           /
```

**ภาพเทียบ — แท่ง 4H แท่งที่ 2 เมื่อซูมดูใน 30M**

| แท่ง 4H แท่งที่ 2 | ใน 30M |
|---|---|
| ไส้ล่าง | จังหวะย่อลง |
| เนื้อแท่งที่วิ่งขึ้น | จังหวะขึ้นกลับไป |
| ลูกศรกลางเนื้อแท่ง | **จุดเข้า Buy** |
| ปิดที่ปลายไส้ของแท่งแรก | กลับไปถึง high เดิม = **wick fill ครบ** |

→ wick fill ใน 4H เห็นเป็นแท่งเดียว แต่ใน 30M คือ "ย่อแล้วขึ้น" ที่ให้จุดเข้าได้

## ข้อสังเกตของเรา (ไม่ใช่คำสอนครู)

- **"Volume" ของครูอ่านจากรูปแท่ง** ใกล้กับ "แรงซื้อขายสุทธิ" มากกว่าจำนวนที่ซื้อขายกันจริง ทองคำ spot ไม่มี volume รวมศูนย์ ใน TradingView เป็น tick volume
- **ในข้อมูลจริง แท่งไส้ยาว (high − low กว้าง) มักมี volume จริงสูง** เพราะสองฝั่งแลกกันหนัก → ถ้าเทียบกับ tick volume อาจได้ผลกลับกับกรอบของครู
- **เทียบกับตำราอื่น:** ครูมองไส้เป็นแรงที่โดนตบกลับเหมือน TA ทั่วไป (rejection) แต่ใช้ไส้ Range เป็น "รอยขนมปัง" บอกทิศต่อ ส่วนสาย SMC ใช้คำว่า "liquidity" หมายถึงจุดที่ stop loss กองกันเหนือ high / ใต้ low ซึ่งคนละความหมายกับของครู
