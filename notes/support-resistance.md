## 1. แนวรับแนวต้านคือจุด confirm

**ครูสอน:** แนวรับแนวต้านเป็น **1 ในจุด confirm** ว่าราคาจะ react ยังไง
- "1 ใน" → ยังมีจุด confirm อื่นอีก (ยังไม่ได้สอน)

## 2. แนวต้านย่อย กับ แนวต้านใหญ่

**ครูสอน:** แนวต้านมี 2 แบบ คือ **แนวต้านย่อย** กับ **แนวต้านใหญ่** (ครูเรียกว่า **Major zone**)

*(จากรูป)*
- **ย่อย:** ราคาย่อนิดเดียวแล้วทะลุขึ้นต่อ ไปทีละขั้นเหมือนขั้นบันได
- **ใหญ่:** วาดเป็น**กล่อง** ไม่ใช่เส้นเดียว · ราคาแตะแล้ว**ร่วงยาว**

## 3. รอดูว่าแท่งปิดตรงไหน

**ครูสอน:** CF (confirm) = ดูว่ามัน react ยังไง → **รอดูว่าแท่งปิดตรงไหน** แล้วค่อยหาจุดเข้า

*(จากรูป — ตัวอย่างที่ Major zone ทั้งสองแบบราคาลงต่อ)*
- แท่งชนโซน → แท่งถัดไป**แดงยาว ปิดต่ำกว่าโซน**
- แท่งที่**ไส้ทะลุโซนขึ้นไป แต่ปิดกลับลงมาใต้โซน** → ตัดสินจากราคาปิด ไม่ใช่ดูแค่ว่าไส้แตะ

## 4. แนวรับย่อย กับ แนวรับใหญ่

**ครูสอน:**
- แนวรับย่อยรับได้แป๊บเดียวก็ทะลุ → แป๊บเดียวทะลุอีก → พอถึง**แนวรับใหญ่** ราคาจะเป็นอีกแบบ
- **แนวรับย่อย** เอาไว้ **Sell สั้น ๆ**
- **แนวรับใหญ่** เอาไว้**กลับตัวขึ้น**

*(จากรูป)* แนวรับใหญ่เป็นกล่องหนากว่าแนวย่อย · แตะแล้วดีดขึ้นแรงเกือบถึงจุดที่เริ่มลง

## 5. ตีแนวให้โดนไส้

**ครูสอน:** ตีแนวรับแนวต้าน**ให้โดนไส้**

*(จากรูป — โซนแนวรับ)*
- **ขอบบน** = ก้นเนื้อของแท่งที่ลงมาต่ำสุด
- **ขอบล่าง** = ปลายไส้ที่ลึกที่สุด
- ไส้หลายแท่ง (~8 แท่ง) จิ้มเข้าโซน แต่**ไม่มีเนื้อแท่งไหนปิดอยู่ในโซน**

## 6. บางคนบอกเข้าโซนแล้ว Buy เลย

**ครูยกมา:** บางคนบอกว่าถ้าราคาเข้าแนวแบบนี้ ให้ **Buy ได้เลย**
> ⚠️ ครูต่อทันทีว่า "**แต่**จะมี case ที่ BO ทะลุ" (§7) → **ไม่ใช่กฎของครู**

## 7. แต่มี case ที่ทะลุโซน

**ครูสอน:** **แต่**จะมี case ที่เป็น **Break out ทะลุโซน** · ครูเขียนบนกราฟว่า **"หลักของเหตุผล"**

*(จากรูป)* ราคาที่อยู่ในโซนไปได้ 2 ทาง — โซนรับแล้วขึ้น หรือโซนแตกแล้วลงต่อ

## 8. ตีเล็กตีใหญ่ก็เหมือนกัน

**ครูสอน:** ไม่ว่าจะ**ตีโซนเล็กหรือตีใหญ่ก็เหมือนกัน** เพราะเรา**รอให้ราคาผ่านไส้หมดก่อน**อยู่แล้ว

*(จากรูป)*
- ครูขีดไว้ที่**ปลายไส้ทุกแท่ง** รวมไส้ที่ยาวโดด
- แท่งที่**เนื้อปิดเลยปลายไส้ทุกอัน** = ✓
- → ความหนาโซนไม่สำคัญ จุดตัดสินคือ**ปลายไส้ที่ลึกที่สุด**

## 9. ไม่ควรเล่นในส่วนของแนวต้าน

**ครูสอน:** สรุปคือ **ไม่ควรเล่นในส่วนของแนวต้าน**
- เราเข้าใจว่า = **ไม่เข้าเทรดตอนราคายังอยู่ในโซน** เพราะยังไม่รู้ว่าจะรับหรือทะลุ (§7) *(รอยืนยัน)*
- ตัวอย่าง §5–§8 เป็นแนวรับ แต่ครูพูดว่า "แนวต้าน" → น่าจะใช้ได้ทั้งสองฝั่ง *(รอยืนยัน)*

## คำถามที่ยังค้าง (ถามครู / ดูคลิปซ้ำ)

**ต้องรู้ก่อน backtest**
- [ ] แยกแนว**ย่อย**กับแนว**ใหญ่**ยังไง — TF ใหญ่กว่า / จำนวนครั้งที่แตะ / ขนาดการกลับตัว?
- [ ] ต้องมีไส้แตะ**กี่แท่ง**ถึงนับเป็นแนว · ตีใน **TF ไหน**
- [ ] "ผ่านไส้หมด" = **เนื้อปิด**เลยปลายไส้ (แบบในรูป) หรือแค่ราคาวิ่งเลยก็นับ
- [ ] ปิดแบบไหนแปลว่าอะไร — ปิดในโซน / ปิดเลยโซนแต่ยังไม่ผ่านไส้ / ผ่านไส้หมด

**จุดเข้า · SL · เป้า**
- [ ] เข้าที่ราคาปิดของแท่งที่ react เลย หรือรออีก 1 แท่ง · ✓ ใน §8 = Sell ตรงนั้นได้เลยไหม
- [ ] SL วางตรงไหน — เหนือ/ใต้โซน หรือเลยปลายไส้
- [ ] Sell สั้น ๆ ที่แนวรับย่อย: เข้าหลังปิดทะลุ หรือรอเด้งกลับมาแตะ · "สั้น ๆ" = เป้าแนวถัดไป?
- [ ] ฝั่งแนวต้านกลับกันไหม — แนวต้านย่อย **Buy สั้น ๆ** / แนวต้านใหญ่กลับตัวลง
- [ ] ถ้าโซนรับ (ไม่ทะลุ) ใช้อะไร confirm

**ความหมาย**
- [ ] จุด confirm อื่นมีอะไรบ้าง (§1)
- [ ] "หลักของเหตุผล" คืออะไร — ใช้อะไรตัดสินว่าโซนจะรับหรือทะลุ (§7)
- [ ] §9 หมายถึงไม่เข้าตอนอยู่ในโซน ใช่ไหม · ใช้กับแนวรับด้วยไหม
- [ ] แท่ง BO ต้องมี volume (เนื้อยาว) ด้วยไหม
- [ ] เนื้อแท่งปิดเข้าไปในโซนแล้ว โซนยังใช้ได้ไหม

**เครื่องหมายในรูปที่ยังไม่รู้ความหมาย** — เลข "1, 2" (รูป §2) · เส้นขาว 2 เส้นในโซน (รูป §6) · เส้นโค้งสีเขียว (รูป §3)

## ข้อสังเกตของเรา (ไม่ใช่คำสอนครู)

- **เชื่อมกับคลาสแท่งเทียน:** ครูเคยยก "แนวรับแนวต้าน" เป็นตัวอย่าง confirm ใน [candlestick-101 §3](candlestick-101.md#3-ไม่มี-range--5050) · "รอปิด" คล้าย [แท่ง confirm §9](candlestick-101.md#9-แท่ง-confirm-และจังหวะเข้า) · BO ต้องมี volume อยู่ใน [§6](candlestick-101.md#6-bo-กับ-volume) — ครูยังไม่ได้บอกว่าใช้ร่วมกัน
- **§2 กับ §4 เหมือนกันแบบกลับหัว:** แนวย่อยแค่ชะลอราคาแล้วโดนทะลุ แนวใหญ่ทำให้กลับตัวแรง และครูวาดกล่องใหญ่หนากว่าเสมอ → ความหนา / ขนาดการกลับตัวอาจเป็นตัวแยก (เดา) · ตำรา TA ทั่วไปก็แบ่ง minor / major
- **§6 vs §3:** Buy ทันทีที่แตะ = ราคาดี SL แคบ แต่ยังไม่รู้ว่าโซนรับไหม · รอปิด = ราคาแย่กว่า แต่รู้ผลแล้ว (ตำราเรียก aggressive / conservative entry)
- **ไส้ทะลุแต่ปิดกลับ (§3):** ตำราทั่วไปเรียก false breakout / rejection · SMC เรียก liquidity sweep
- **§8 ทำให้ BO เหลือราคาเดียว** = ปลายไส้ลึกสุด → เขียนโปรแกรมหาได้ ไม่ต้องเดาความหนาโซน
