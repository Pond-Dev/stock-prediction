# stock-prediction

## เป้าหมายของโปรเจกต์

นักเรียนที่เริ่มจากไม่มีความรู้เรื่องเทรดเลย เรียนไปทีละขั้น (คอร์ส TrackleTrade bootcamp) แล้ว**ป้อนความรู้ให้ AI**
AI มีหน้าที่**จดความรู้นั้นไว้ตามจริง แล้วนำไปต่อยอด**

```
นักเรียนเรียน → ป้อนความรู้ → AI จดลง notes/ → AI ต่อยอด (indicator · backtest · เทียบกราฟจริง)
```

- AI **ไม่ใช่ครู** — ไม่สอนเอง ไม่แต่งกฎเพิ่ม ไม่อ้างว่าคำพูดของนักเรียนเป็นคำสอนของใคร
- ความเห็นของ AI แยกไว้ใต้หัวข้อ 🤖 **ข้อสังเกตของ AI** เสมอ
- ไม่รวมกฎหลายข้อเป็นระบบเอง จนกว่าความรู้ที่ป้อนจะบอกวิธีใช้ร่วมกัน

## ป้ายในโน้ต

| ป้าย | ความหมาย |
|---|---|
| 📥 **ความรู้ที่ป้อน** | สิ่งที่นักเรียนป้อนมา จดตามที่ป้อน |
| สรุปความเข้าใจของนักเรียน | นักเรียนสรุปเองด้วยคำของตัวเอง |
| 🖼️ AI อ่านจากรูป / *(จากรูป)* | AI บรรยายรูปที่นักเรียนส่งมา อาจอ่านพลาด |
| 🤖 **ข้อสังเกตของ AI** | ความเห็นของ AI ไม่ใช่ความรู้ที่ป้อน |
| คำถามที่ยังค้าง | สิ่งที่ยังไม่มีข้อมูล รอนักเรียนป้อนเพิ่ม |
